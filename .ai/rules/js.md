# Js

## Use Inertia and the shared UI for market-data pages
Place Inertia pages in `resources/js/pages`, reuse shared layouts and `@/components/ui` primitives, and use Wayfinder `@/routes` or `@/actions` imports for Laravel links and forms. Translate market-data UI into `km` and `en`. Show source attribution, effective dates, and accessible loading, empty, error, and stale states. Display only verified market values.
